Automatic upload from Claude Code (hook)

Sessions push themselves here when a turn ends (throttled to once per 10 minutes) and when a session ends. On the machine running Claude Code:

curl -fsS {{ base }}/hook/{{ hook_name }} -o ~/.local/bin/chat-search-push
chmod +x ~/.local/bin/chat-search-push
mkdir -p ~/.config/chat-search && printf 'CHAT_SEARCH_URL=%s\nCHAT_SEARCH_TOKEN=%s\n' '{{ base }}' '<token>' > ~/.config/chat-search/config
chmod 600 ~/.config/chat-search/config
~/.local/bin/chat-search-push --check      # prints your user name if the token works

Then add to ~/.claude/settings.json (merge into an existing hooks block if you have one):

{
  "hooks": {
    "Stop":       [{ "hooks": [{ "type": "command", "command": "~/.local/bin/chat-search-push" }] }],
    "SessionEnd": [{ "hooks": [{ "type": "command", "command": "~/.local/bin/chat-search-push" }] }]
  }
}

The hook reads the transcript path from its stdin, gzips the file and POSTs it to /api/upload in the background — it never blocks Claude. Subagent transcripts next to the session are pushed too. Re-pushing a session replaces the copy held here, so the index always has the latest.

Manual push of any file: ~/.local/bin/chat-search-push path/to/session.jsonl
